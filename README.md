## Compatibility

The target version is Minecraft Java 1.21.1. Extra Glow Berries item glow requires OptiFine or compatible emissive-texture support. The powered Observer's full-bright accents are not supported by vanilla 1.21.1. Redstone Wire and the branch variants of logs retain source issues with their particle textures.
